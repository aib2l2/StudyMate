# StudyMate Campus — разобраться вместе

Локальный сайт для взаимной помощи студентов Astana IT University. Найти старшекурсника по конкретной теме, записаться на полчаса, получить материалы и проверить понимание после встречи. Telegram и внешний сервер для демонстрации не нужны.

## Запуск на Mac

В этой папке выполните:

```bash
./scripts/setup.sh
./start.command
```

Откройте [StudyMate](http://127.0.0.1:8000). После установки можно запускать двойным нажатием на `start.command`. Остановка — Ctrl+C в окне запуска. Нужен Python 3.11–3.13; первичная установка зависимостей требует интернет. Готовая сборка интерфейса и иллюстрация входят в проект. Для изменений интерфейса нужен Node.js 20+ с npm.

После установки демонстрация работает локально без интернета. Внешняя ссылка на видеозвонок или учебные материалы откроется только при наличии интернета; сам StudyMate звонки не проводит.

## Что показать преподавателю

На главной — открытый каталог. В верхней полосе нажмите **«Режим защиты»** и выберите учебную роль:

- Аликхан — студент: поиск, заявка, заметки, тесты, отзыв.
- Аяулым — ментор: свои ученики, подтверждение, материалы, календарь.
- Ерлан — второй студент: проверка занятости и изоляции аккаунтов.
- Команда — проверка анкет, отдельная приостановка, предметы и показатели.

Кнопка открывает аккаунт только после явного выбора. После выхода автоматического входа нет. Все профили, отзывы и история в демонстрации вымышлены.

Сценарий на 3–4 минуты: найдите Аяулым по SQL JOIN, выберите время, опишите вопрос. В роли Аяулым откройте заявку, добавьте HTTPS-ссылку на звонок или место на кампусе и подтвердите. Сохраните материалы. В деморежиме есть явно помеченная кнопка раннего завершения; затем студент подтверждает, что встреча состоялась, проходит тест и оставляет отзыв. [Подробный сценарий и речь на английском](docs/DEFENSE.md).

## Что работает

- Публичные главная, каталог и анкеты; регистрация и вход по email/паролю.
- **2.2:** переписка на странице встречи и мгновенные уведомления без перезагрузки; поиск по имени, теме и словам из анкеты, сортировка по цене и рейтингу, избранные менторы, объяснимые рекомендации «Вам может подойти»; лист ожидания сам оповещает о подходящем времени; недельные серии интервалов, перенос встречи по согласию обоих, экспорт в календарь (.ics); групповые занятия на 2–5 человек с ценой за место.
- Смена пароля, выход на всех устройствах, восстановление доступа по одноразовому коду от владельца сайта и выгрузка своих данных в JSON (кабинет → «03 / Безопасность и данные»).
- Отдельные кабинеты студента, ментора и команды. Одна учётная запись может учиться и объяснять.
- Поиск по теме, кампусу, языку, бюджету, формату и времени до дедлайна. Изменённые фильтры нужно применить; старые результаты до этого выбрать нельзя.
- Резерв на 15 минут, проверка пересечений с обеих сторон, подтверждение/отклонение/отмена.
- Страница встречи со ссылкой или аудиторией, материалами и раздельными личными заметками.
- Завершение: отметка ментора → подтверждение студента → отзыв и XP.
- Календарь различает свободное, ожидающее, занятое, состоявшееся и закрытое время. Закрытие интервала сохраняет историю; закрытый интервал можно открыть снова.
- Тесты до/после содержат разные вопросы. По шести темам есть 36 вопросов с объяснениями. Повторное прохождение не даёт повторный XP за тот же этап темы.
- «Зачётка» показывает опыт по предметам и достижения. Тест не выдаётся за доказательство полного знания предмета.
- Уведомления и напоминания внутри сайта, с сохранением в SQLite. Пока сайт открыт, данные обновляются каждые 12 секунд. Письма и push-уведомления не отправляются.
- Отдельная приостановка анкеты командой: личный переключатель ментора не обходит её.
- Демо-расчёт комиссии; фактическое списание всегда 0 ₸.
- Светлая/тёмная темы, мобильное меню, адрес каждой страницы и работа обновления/«назад».

## Режимы и данные

По умолчанию `.env` содержит `APP_MODE=demo`: данные находятся в `data/demo.sqlite3`. При обновлении существующая база автоматически получает новые поля; записи и результаты сохраняются. Перед этой переработкой сделана отдельная резервная копия.

Для пустой базы собственных аккаунтов остановите сайт и укажите:

```dotenv
APP_MODE=site
DATABASE_PATH=
WORKER_ENABLED=1
COMMISSION_PERCENT=15
```

Пустой путь выбирает `data/site.sqlite3`. Демовхода и вымышленных людей там нет; учебный каталог остаётся. Зарегистрируйтесь через сайт. Роль команды не выдаётся по совпадению email: владелец Mac назначает её существующему аккаунту при остановленном приложении:

```bash
PYTHONPATH=backend .venv/bin/python -m studymate admin --email your-account@example.com
```

В режиме `site` завершать встречу можно только после её запланированного окончания. Режимы используют разные файлы; site-режим отказывается открывать файл с `demo` в имени. Старое значение `APP_MODE=live` распознаётся как `site`; старые Telegram-настройки не используются.

Забытый пароль: остановите сайт и выдайте одноразовый код (действует 30 минут):

```bash
PYTHONPATH=backend .venv/bin/python -m studymate reset-password --email user@example.com
```

Пользователь вводит код на странице входа → «Забыли пароль?». После сброса все его сессии завершаются.

Поисковый индекс строится автоматически. Если вы правили базу вручную, пересоберите его при остановленном сайте: `PYTHONPATH=backend .venv/bin/python -m studymate reindex`.

Если демонстрационные даты устарели, можно остановить сайт и выполнить `./scripts/reset-demo.sh`. Это удалит **все собственные демозаписи** и заново создаст учебный пример; делайте это только когда данные не нужны. Site-база не затрагивается.

## Разработка и проверки

```bash
./scripts/test.sh          # ruff, pytest + покрытие, Prettier, ESLint, сборка, Vitest
E2E=1 ./scripts/test.sh    # плюс сценарий защиты в Playwright (нужен Google Chrome)
```

Фронтенд отдельно (в `frontend/`): `npm run dev`, `npm run lint`, `npm run format`, `npm test`, `npm run e2e`, `npm run build`. После изменения ответов API выполните `npm run gen:api`: он обновит `docs/openapi.json` и `src/api-schema.d.ts`, а `tsc` проверит, что типы интерфейса им соответствуют. Документация API на запущенном сайте: <http://127.0.0.1:8000/docs>.

Структура кода описана в [ARCHITECTURE.md](docs/ARCHITECTURE.md), изменения — в [CHANGELOG.md](CHANGELOG.md). GitHub Actions выполняет те же проверки (`.github/workflows/ci.yml`).

[Результаты проверки](docs/VERIFICATION.md), [устройство приложения](docs/ARCHITECTURE.md), [визуальная концепция и иллюстрация](docs/DESIGN.md).

Это локальный учебный прототип. Подтверждение email, восстановление пароля по email, реальная оплата, видеосвязь и публичное размещение не реализованы. Для публичного запуска потребуются HTTPS, проверка владения email, восстановление доступа, резервное копирование и отдельная проверка защиты/нагрузки. Приложение по умолчанию слушает только `127.0.0.1`.
